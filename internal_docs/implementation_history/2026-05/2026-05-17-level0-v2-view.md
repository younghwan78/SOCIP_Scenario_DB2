# Level0 V2 View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild Level0 viewer behavior around scenario resource usage, buffer/data flow, endpoint details, and subsystem power/BW summaries across Exynos2600 camera, video, game, display, and audio scenarios.

**Architecture:** Add a backward-compatible Level0 v2 contract to `ViewResponse`, then implement new projection helpers that emit `resource` overview rows and `topology` graph nodes from the resolved canonical graph. Streamlit will render Level0 as a resource dashboard plus a buffer-aware topology graph, while existing Level1/2 behavior remains unchanged.

**Tech Stack:** Python 3.11+, Pydantic v2, FastAPI, SQLAlchemy-backed canonical graph repository, Streamlit, existing ELK/SVG renderer, pytest.

---

## Scope

### In Scope

- Level0 only.
- New `level=0&mode=resource` view data.
- Revised `level=0&mode=topology` that uses active scenario nodes and buffers, not Android stack filler.
- Backward-compatible optional fields on `ViewResponse`.
- Exynos2600 fixture coverage for camera, video playback, YouTube, game, game streaming, audio, voice/video call.
- Dashboard rendering for resource table, selected endpoint details, topology graph, and metric summary.

### Out Of Scope

- Level1 and Level2 redesign.
- Write API changes.
- New database tables.
- Authentication, deployment, or production operations.
- Large asynchronous exploration jobs.
